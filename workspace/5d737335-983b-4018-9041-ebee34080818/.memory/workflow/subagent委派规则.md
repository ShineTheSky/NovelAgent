# 正确委派流程

## 错误做法
自己读完 review 报告后，提炼成"修改清单"传给 SubAgent。

**问题**：
- SubAgent 看不到完整的审阅逻辑
- 如果我解读有偏差，SubAgent 也会跟着走偏
- SubAgent 无法根据实际情况灵活调整

## 正确做法
1. **传递完整上下文**：把 review 报告完整地作为附件传给 SubAgent
2. **明确修改范围**：在 task 里写清楚要修改哪些部分、修改依据是什么
3. **让 SubAgent 自己理解和执行**：SubAgent 有独立上下文，可以根据完整报告判断如何修改

## 示例

**错误示范**：
```
task: 润色第4-5章，删除重复对话，调整林深心态
```

**正确做法**：
```
task: 润色第4-5章，按照附件中的审阅报告进行修改
attachments: [review报告完整内容]
```

# 相关案例

## 案例：第四章&第五章润色

**用户操作**：让我 review 第四章和第五章 → 然后让我调用润色 subagent

**我的错误做法**：
1. 自己完成 review，写了详细审阅报告
2. 把报告中的问题提炼成"修改清单"写进 task
3. 调用 `chapter_polisher`，没有传递完整 review 报告

**用户反馈**："没有将之前的 review 结果传给他嘛？"

**问题本质**：SubAgent 收到了修改指令，但看不到我判断问题的逻辑

**正确的做法应该是**：
1. 完成 review，写审阅报告
2. 调用 `chapter_polisher` 时，把完整 review 报告作为附件传入
3. task 里写："按照附件中的审阅报告进行修改"
