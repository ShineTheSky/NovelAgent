## 问题

当主 agent 调用 reviewer SubAgent 时，虽然在 attachments 中传递了第一章内容，但 reviewer 仍然读取了文件而非优先使用 attachments。

主 agent 也犯了另一个错误：没有保存 reviewer 的完整报告到文件，而是自己提炼后传给下一个 agent。

## 正确流程

1. 主 agent 调用 reviewer SubAgent，在 attachments 中附上待审查内容
2. **Task 明确指示**："不要读取文件，直接使用 attachments 中的内容进行审查"
3. reviewer 返回完整报告
4. 主 agent **保存完整报告**到文件（如 `.memory/review/ch01_review.md`）
5. 调用下一个 SubAgent（如 chapter_polisher），attachments 附上完整报告
6. **Task 明确指示**："参考附件中的审阅报告修改，不要读取项目文件"

## 关键点

- 主 agent 不应提炼 reporter 的报告内容
- attachments 应包含所有必要上下文
- Task 描述需要明确"不要读取文件"
