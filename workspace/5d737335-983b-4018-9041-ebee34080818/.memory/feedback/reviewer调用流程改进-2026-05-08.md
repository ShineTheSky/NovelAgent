name: reviewer调用流程改进
description: reviewer SubAgent没有优先使用attachments的问题
type: feedback
tags: [reviewer, attachments, 工作流程]
summary: 调用reviewer时需明确禁止读取文件，完整报告需保存后传给polisher
---

**问题**：reviewer SubAgent 在 attachments 中传递了完整内容后仍然读取了文件，说明没有优先使用 attachments。

**改进**：
1. 调用任何 SubAgent 时，在 task 指令中明确写"不要读取文件，直接使用 attachments 中的内容"
2. reviewer 返回完整报告后，需要保存到文件（如 `.memory/review/` 目录）
3. 传给下一个 Agent（polisher）时，attachments 附上完整报告，不要自己提炼

**文件位置**：`config/subagent_presets.yaml` 存放 SubAgent 预设配置
