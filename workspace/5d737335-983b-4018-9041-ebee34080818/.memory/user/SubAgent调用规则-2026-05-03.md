## 规则
用户多次强调并纠正：

1. **所有创作任务**必须调用 `chapter_writer` SubAgent
2. **所有审查任务**必须调用 `reviewer` SubAgent
3. **禁止直接输出**：读取文件后分析输出属于违规行为
4. **SubAgent调用失败时**：应该重试或向用户说明，等待指示，而不是自行补救
5. **传递完整上下文**：审查后修改的工作流，必须把完整的审查报告传给下一个 Agent，不要自己提炼"修改清单"

## 违反案例
- 写第四章时：正常调用了SubAgent
- 写第五章时：SubAgent未返回结果，我直接输出了内容（违规）
- Review第四章和第五章：我没有调用SubAgent，直接读取文件后自己分析输出（严重违规）

## 正确做法
当SubAgent调用失败时：
1. 重试一次
2. 检查参数是否正确（如attachments）
3. 向用户说明情况，等待指示
4. 禁止自行完成后再输出
