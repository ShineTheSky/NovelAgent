## 问题
即使在 attachments 中传递了完整文件内容，reviewer SubAgent 仍然会读取文件。

## 解决方式
在 reviewer 的 system prompt 顶部添加优先规则：

```yaml
priority_rule: |
  ## 重要：优先使用 attachments
  你应优先使用以下 attachments 中提供的文件内容进行分析。
  如果 task 中包含 attachments，必须直接使用其中的内容，禁止再读取文件。
  禁止在分析过程中调用 Read 工具读取已提供的文件。
```

## 配置位置
config/subagent_presets.yaml

## 补充说明
也可在 task 参数中加一句："attachments 中已提供完整的文件内容。不需要再读取文件，直接使用 attachments 内容进行分析。"
