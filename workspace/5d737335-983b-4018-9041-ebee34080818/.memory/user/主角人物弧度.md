## 主角人物弧度要求

### 初始状态
- 性格：浑浑噩噩、随波逐流
- 态度：**麻木虚无**，对世界没有强烈的追求或信念
- 生活方式：得过且过，用危险任务麻痹自己，空虚感深埋

### 转折点
- 在某个重要角色"零"的影响下开始改变
- 零的信念/行动/遭遇触动了主角
- 主角开始思考、质疑、成长

### 最终状态
- 形成了自己的信念
- 在故事结尾实现高光时刻
- 完成从"无信念"到"有信念"的人物弧度

这是贯穿全篇的核心角色成长线，需要通过具体事件逐步铺垫。
