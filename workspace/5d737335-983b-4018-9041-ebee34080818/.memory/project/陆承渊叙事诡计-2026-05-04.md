陆承渊的叙事诡计设计：

1. **从一开始**就把他塑造成"集团下一代CEO/创始家族嫡系"——读者知道他有背景、他是继承人
2. **第2章通过老K揭示**他的家族背景——这是正确的设计
3. **真正的戏剧冲击力**：不是"他是谁"的反转，而是——即使是这样的嫡系血脉，他死了立刻有人顶替，集团连眼睛都不眨一下
4. **核心主题**：他至死以为自己是主角，其实只是可替换的零件
