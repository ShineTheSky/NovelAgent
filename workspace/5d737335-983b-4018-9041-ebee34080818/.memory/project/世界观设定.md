# 世界观设定

## 背景故事
- 时间：地球毁灭后约100年
- 事件：一颗大型小行星撞击地球，地球被摧毁
- 碎片带：由地球碎裂形成的岩石、金属、土壤组成的小行星带
- 人类生存：人类在太空站和小行星碎片上建立了勉强维持生命的聚落

## 科技水平
- 基础：核聚变能源、离子推进器、生态循环舱
- 义体改造：神经接口、机械肢体、记忆存储（赛博朋克元素）
- 通讯：量子加密通讯网络（脆弱）
- 运输：穿梭机、各类小型飞船

## 社会结构
- 中央联邦：名义上的管理机构，控制主要资源和通讯
- 碎片城邦：各地球碎片上的独立聚落
- 拾荒者：专门在碎片带中搜寻地球遗留资源的群体
- 边缘人：被遗忘在偏远碎片的底层人民

## 核心冲突
- 资源匮乏：维持生命的物资永远不够
- 身份认同：在太空中漂泊的人类如何定义自己
- 技术伦理：义体改造带来的身体与心灵的张力
- 生存希望：是否应该寻找新的家园

## 关键地点
1. 核心站（原联合国总部残骸改建）
2. 零号碎片（原喜马拉雅地区碎片，最大人类聚居地）
3. 寂静带（通讯死角，匪徒和亡命徒的乐园）
4. 创世引擎（传说中的巨型飞船，人类最后的希望）

## 视觉风格
- 霓虹与锈迹并存
- 狭窄封闭的空间 vs 浩瀚无垠的宇宙
- 地球遗留的废墟美学
- 人工光源（人造太阳、LED灯）与永恒黑暗的对比
