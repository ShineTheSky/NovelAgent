**《空气》主角能力核心设定**

林息可化为空气形态，具备以下能力与限制：

| 能力 | 说明 |
|------|------|
| 化为空气 | 身体变为空气，可穿越任何障碍 |
| 空气震动发声 | 可通过空气震动发出声音，但极其微弱 |
| 影响范围 | 只能影响极轻物体（纸张、布料、灰尘） |

**发声限制条件**（第7章沈焰对话的逻辑基础）：
- 只能近距离（约1米内）
- 需要安静环境
- 声音微弱，像风中的低语

**观察机制**：
- 作为空气没有眼睛
- 通过感知空气流动、震动、温度变化来"看见"周围环境

此设定与第3章"推动物体"需保持一致：只能推动极轻物体，触碰人类时是虚无。
