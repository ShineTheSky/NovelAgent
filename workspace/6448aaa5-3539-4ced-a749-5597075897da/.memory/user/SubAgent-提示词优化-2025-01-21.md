## 问题现象
调用 SubAgent（outliner）修改大纲时，输出被截断，只完成了部分任务。

## 原因分析
提示词包含大量列表项和描述，SubAgent "思考过多" 导致输出被截断。

## 优化后的提示词模板

```
修改大纲 outline.md，修复审阅报告中的问题。

## 修改清单（逐项执行）

**能力一致性（2处）**
1. 第3章：将"原文"改为"新文"
2. 第6章：将"原文"改为"新文"

**逻辑漏洞（4处）**
3. 第5章：...【原文】
4. 第7章：...【原文】
5. 第9章：...【原文】
6. 第5章：...【原文】

## 执行要求
1. 逐项修改，每修改完一项用【完成】标注
2. 全部完成后，用【修改完成】结束
3. 输出格式：逐项报告修改状态，最后汇总
```

## 关键改进点
| 改进 | 说明 |
|------|------|
| 明确编号 | 每项修改带编号，便于追踪 |
| 明确原文 | 修改项带原文，确保准确修改 |
| 明确新文 | 告诉 SubAgent 改成什么 |
| 分步报告 | 每项标注【完成】，最后汇总 |
| 压缩描述 | 去掉冗长的解释，直接给修改指令 |
